# 型別錯誤

先查看 Exceptions.original_value 與 source_row，判斷規則問題或來源問題。
`1,234.50`、`NT$100` 等格式需要明定分隔符／貨幣規則，不能任意移除所有非數字字元。
日期 `01/02/2026` 有歧義，schema 應指定 `%d/%m/%Y` 或 `%m/%d/%Y`；不要猜測。
識別碼用 string；若來源在 Excel 已把 `001234` 存成數字 1234，必須取得原始值或明確補零規則。
缺值保持 missing，失敗轉型的原始值放入 Exceptions。小數轉 integer 不得截斷。
超出浮點／整數精度能力的金額改用 Decimal 或最小貨幣單位；先確認尺度與捨入規則。
